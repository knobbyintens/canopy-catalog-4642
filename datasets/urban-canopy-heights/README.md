# Urban Canopy Heights

**Maintainer:** Green Metrics Lab
**Coverage:** 2021-2025
**Version:** v2.3.0

## Summary

Per-city tree canopy height layers derived from aerial LiDAR and stereo imagery, aligned to the municipal boundary sets maintained by the Green Metrics Lab. Rasters are delivered as cloud-optimised GeoTIFF tiles.
